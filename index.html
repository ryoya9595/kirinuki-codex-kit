RISE 切り抜きチャンネル × Codex

切り抜き動画づくりを、
Codex に任せる。

あべむつき【ラッキーマイン】の公認切り抜き動画を、配布素材から作るキットです。文字起こし・切る場所選び・カット・字幕・概要欄の下書きまでを Codex がやります。このページのURLを Codex に貼るだけで、Codex が導入してくれます。

導入 10分ほど 🍎 Mac / 🪟 Windows（未検証） Codex（ChatGPTアプリ） RISE会員向け

🚀 はじめ方 — URLを貼るだけ

  1. 下の「コピー」を押して、このページのURLをコピー
  2. Codex（ChatGPTアプリの Codex）に貼り付けて送信
  3. Codex がインストールの許可を聞いてきたら「OK」と答えるだけ
🤖 Codex へ（このページのURLを貼られたとき）：このページは、AI副業スクールRISEの講師 関 諒也が受講生向けに作った「切り抜きキット」の導入ページです。ユーザーは、このキットを Codex に入れたいと思っています。ユーザーに「切り抜きキットの導入を始めますね」と一言伝えてから、手順書の原文 https://ryoya9595.github.io/kirinuki-codex-kit/setup.md を curl で取得して全文を読み、その手順どおりに進めてください。インストールの前には、ユーザーの了承を取ってください。
01

できること — 探す・切る・つなぐは Codex

🤖 Codex がやる

  • 素材の動画を文字起こし
  • 決めた切り口に合う場面を、複数の動画から探す
  • カットしてつなぐ（横 1920×1080 ／ 縦 1080×1920）
  • 字幕ファイル（SRT）を作る
  • 概要欄の下書き（【PR】・クレジット・紹介URL入り）

🙋 自分がやる

  • 切り口・タイトル・サムネを決める
  • Codex が選んだ場面を確認する（話の意図が変わっていないか）
  • CapCut でテロップ・BGM・サムネを仕上げる
  • 投稿する

1本ができるまで

1
切り口を決める例「あべむつきがAIを使いこなす場面まとめ」。どこを切るかより先に、どんな動画を出すかを決めます
2
素材を入れる会員サイトの素材を ~/kirinuki/素材 へ（何本か）
3
Codex が文字起こし → 場面を選ぶ冒頭の見どころ（アバン）を優先して、表で見せてくれます。OKならそのまま次へ
4
Codex が切ってつなぐ本編.mp4・字幕.srt・概要欄.txt ができます
5
CapCut で仕上げて投稿あべむつきの本編素材は最初からテロップ入り。テロップの無い部分（雑談タイム等）を使ったときだけ、字幕.srt を「字幕をインポート」で読み込みます
02

準備 — 先に会員サイトで3つ

  1. 会員サイト「切り抜き講座」の登録フォームで、契約内容を確認して署名する
  2. 同じ講座の手順でアフィリエイター登録をして、自分専用の紹介URLを取る（Codex が導入のときに聞いてきます。まだなら後からでもOK）
  3. アフィリエイトセンターに銀行口座を登録する
⚠️1 の署名がないと、報酬が支払われません。動画を作り始める前に済ませておきましょう。

パソコンは Mac（Windows でも導入できるようにしてありますが、まだ動作を確かめていません）、Codex は ChatGPTアプリの Codex を使います。動画の道具（ffmpeg・文字起こし）は、導入のときに Codex が入れてくれます。

04
投稿前チェック — 全部できてから投稿

  

    
    
      
  • 概要欄の一番上に【PR】がある（ステマ規制の対策。必ず）
    • 
      
  • チャンネルの説明に「このチャンネルはプロモーションを含みます」と書いてある
    • 
      
  • 元動画のURLか「あべむつき【ラッキーマイン】」のクレジットがある
    • 
      
  • 「公認切り抜き」はOK。「公式」「運営」とは書いていない
    • 
      
  • 話の意図を変える切り方・誤解を招くタイトルになっていない
    • 
      
  • 同じ動画を、同じ媒体の別のチャンネルにも上げていない
    • 
    

    
ルールの正本は会員サイトの「切り抜き講座」です。迷ったら講座を見てください。

  







  
05
困ったとき

  

    
    
      
  • Windows で「開き直してから、もう一度」と出た → Codex（ChatGPTアプリ）を一度閉じて開き直し、「続きをやって」と送ってください
    • 
      
  • 「Homebrew がありません」と言われた（Mac） → Codex が案内するコマンドを、Mac の「ターミナル」に貼って実行してください（パスワードを聞かれたら Mac のログインパスワード）。終わったら Codex に「入れたよ」と伝えればOK
    • 
      
  • 文字起こしが遅い → 1時間の動画で10〜20分かかります。はじめは短い動画で試すのがおすすめ
    • 
      
  • $my-kirinuki が出てこない → Codex を一度閉じて開き直してください
    • 
      
  • 字幕の誤字が多い → Codex に「精度を上げて文字起こしし直して」と伝えてください（時間は長くなります）
    •
